# Comments Pass

Do a complete documentation-comment pass over the given file or
codebase: Swagger annotations for HTTP surfaces, JSDoc for exported
functions, types, and modules.

Document what the code does, not what it should do. Flag stale or
contradictory comments you find instead of silently rewriting them.
Never change behavior — comments only.
